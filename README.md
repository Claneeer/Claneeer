## 🚀 Projetos em destaque

Plataforma de comunicação em tempo real com mensagens, grupos, canais e funcionalidades de voz e vídeo.

- Organização de usuários, grupos e canais.
- Persistência de dados com Entity Framework Core.
- Comunicação em tempo real com SignalR.
- Integração com WebRTC.
- Serviços de autenticação e gerenciamento de arquivos.

**Tecnologias:** C#, .NET 8, ASP.NET Core, Blazor, EF Core, PostgreSQL, SignalR e WebRTC.

Sistema web para gerenciamento de concessionária, contemplando estoque, clientes, funcionários e vendas.

- Operações CRUD.
- Autenticação baseada em JWT.
- Dashboard com indicadores de vendas e estoque.
- Integração entre aplicação web e API.

**Tecnologias:** Python, FastAPI, React, MongoDB e Docker.
